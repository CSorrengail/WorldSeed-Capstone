# Meta-Schema Stress-Test Examples

Add small, contrasting game schemas here only after agreeing on their purpose and representation. Planned examples include tactical fantasy, narrative, political/faction, and experimental games.

`change-ledger.v0.1.example.json` is intentionally not a game schema. It demonstrates the separate source, interpretation, decision, and immutable-revision workflow.

`structured-rule-draft.v0.1.example.json` demonstrates the intermediate output required from a model-guided design conversation before canonical schema translation.
