# SRD 5.1 Reference Source

The 2014-5e stress-test example is informed by the System Reference Document 5.1, not by a full transcription of Dungeons & Dragons rulebooks. The local PDF is intentionally stored outside the Git repository as reference material.

Source: [System Reference Document 5.1](https://media.wizards.com/2023/downloads/dnd/SRD_CC_v5.1.pdf)
